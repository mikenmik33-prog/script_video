# AI Video Generator

Локальний вебзастосунок для автоматизованої підготовки матеріалів для
коротких вертикальних відео (YouTube Shorts / TikTok) з однієї теми:

`ідея → сценарій+озвучка → [затверджую] → субтитри+готові файли`

**Без картинок і без відео:** застосунок генерує лише ТЕКСТ і
ОЗВУЧКУ - жодних картинок сцен чи автоматичного відео. Для кожної
сцени Google Gemini пише детальний текстовий промт (опис сцени) і
рекомендований промт руху камери - обидва готові для копіювання в
Google Flow (чи будь-який інший text-to-video інструмент), який одразу
згенерує готове відео сцени напряму, без проміжного фото. Раніше
картинки генерувались платно через fal.ai, але виявилось простіше й
надійніше одразу передавати детальний промт у text-to-video, ніж
генерувати проміжне фото.

**Поетапна генерація з ручним затвердженням:** пайплайн зупиняється й
чекає на користувача, а не проганяє все одразу до кінця:
1. Генерується сценарій (текст + детальний промт кожної сцени +
   рекомендований промт руху камери) і озвучка - користувач бачить
   реальний текст і тривалість кожної репліки, може відредагувати
   текст чи промт будь-якої сцени вручну (озвучка для зміненої
   репліки перегенерується автоматично, решта сцен не чіпається).
2. Після натискання «Затвердити сценарій» одразу готуються субтитри й
   фінальні файли.

Застосунок використовує зовнішні сервіси: Google Gemini API для сценарію та
edge-tts для озвучки. Якщо сервіс або ключ недоступний, генерація
завершується помилкою — тестових сценаріїв і беззвучних підмін немає.

**Без монтажу:** застосунок видає готові МАТЕРІАЛИ (аудіофайли
озвучки, .srt субтитри, script.json з промтами кожної сцени) - відео
кожної сцени користувач отримує сам через Google Flow (чи інший
text-to-video інструмент) за готовими промтами з script.json, а
фінальний монтаж робить у будь-якому відеоредакторі (CapCut, Premiere
тощо). Автоматичний FFmpeg-монтаж (колишній `backend/editor.py`)
свідомо повністю прибрано з проєкту - він був найважчим
CPU-навантаженням і найчастішою причиною примусових рестартів на
слабкому безкоштовному хостингу.

**Синхронізація аудіо/субтитрів:** тривалість кожної сцени не
фіксована наперед - вона визначається РЕАЛЬНОЮ тривалістю згенерованої
озвучки (voice_generator вимірює аудіофайл через ffprobe вже після
синтезу мовлення). Тому субтитри й голос завжди збігаються, скільки б
не тривала репліка. Ця реальна тривалість (до сотих секунди) для
відео не підходить - Google Flow вміє генерувати кліпи лише фіксованої
довжини (4, 6 чи 8 секунд), тому окремо порахований `flow_duration`
(найближче з цих трьох чисел) показується користувачу як підказка,
яку тривалість обрати в самому Flow.

**Переклад українською для нерідної мови:** якщо обрано мову, відмінну
 від української (наразі англійська), Google Gemini додатково пише
`translation_uk` для кожної репліки й `full_text_uk` для всього
сценарію. Переклад показується одразу на етапі перегляду сценарію
(`script_review`) - під кожним текстовим полем репліки й над списком
сцен - а не лише у фінальному результаті, щоб користувач розумів зміст
репліки, редагуючи англійський текст.

**Числа в озвучці та субтитрах:** Google Gemini генерує для кожної сцени
`voice_text` (для голосу, числа словами у правильному відмінку: «у
1986 році» -> «у тисяча дев'ятсот вісімдесят шостому році») і
`subtitle` (для екрану, числа цифрами: «у 1986 році»).

**Промт кожної сцени** (`visual_prompt`) завжди кінематографічний
(глибина кадру, якість кінокадру), точно відповідає конкретному факту
цієї репліки (а не загальній темі відео), враховує згадану епоху/рік
(історичні деталі замість сучасних, якщо йдеться про минуле) і НЕ
містить вигаданих персонажів - лише реалістична сцена/фон.

**Рух камери** (`motion_prompt`): Google Gemini для кожної сцени оцінює її дію
(спокійна розповідь, наближення до деталі, погоня тощо) і сам обирає
один з ~40 стандартизованих кінематографічних промтів руху камери
(`backend/camera_movements.py`: панорама, наїзд, відліт дрона, орбіта
навколо об'єкта тощо) - готовий текст під саме цю дію сцени.

**Перехід у наступну сцену** (`transition_prompt`): Google Gemini враховує
зміст ОБОХ сусідніх сцен і сам обирає, як саме змонтувати перехід між
ними - `backend/transitions.py` (hard cut, match cut на тому самому
предметі/русі, cross-dissolve при зміні настрою/епохи, whip pan чи
zoom punch для динамічного моменту, slide wipe для списку/порівняння,
flash cut для сильного акценту, fade to black лише в самому кінці
відео). Це підказка для ручного монтажу (CapCut, Premiere тощо) -
раніше переходи призначались просто по черзі (fade/cut/slide),
незалежно від змісту сцен.

**Ідеї для відео від Gemini:** на головній сторінці над формою - десять
свіжих тем для коротких відео. Gemini підбирає їх окремо для кожної мови
й аудиторії (спочатку English/US), без зовнішнього пошуку. Кнопка "Оновити"
генерує нову десятку, а клік на картку підставляє назву у форму.

## Технології

- Frontend: HTML/CSS/JavaScript (без фреймворків)
- Backend: Python, FastAPI

## Встановлення

1. Встановіть FFmpeg (потрібен у PATH - використовується лише для
   вимірювання й нормалізації тривалості аудіофайлів озвучки):
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - macOS: `brew install ffmpeg`
   - Windows: завантажте з ffmpeg.org і додайте `ffmpeg.exe` у PATH

2. Встановіть залежності Python:
   ```
   pip install -r requirements.txt
   ```

3. Створіть файл `.env` на основі `.env.example` і додайте ключі:
   ```
   cp .env.example .env
   ```
   Щоб генерувати сценарій, отримайте ключ на
   https://aistudio.google.com/app/apikey і впишіть його як `GEMINI_API_KEY`
   у `.env`. Якщо Gemini API недоступний або ліміт вичерпано, генерація
   покаже помилку.

   Озвучка (edge-tts) ключа не потребує - працює одразу "з коробки".
   Це публічний безкоштовний сервіс без офіційного SLA, тому теоретично
   може стати недоступним чи змінитися без попередження — у такому разі
   генерація покаже помилку.

## Запуск

З кореня проєкту:
```
uvicorn backend.server:app --reload
```
Відкрийте http://127.0.0.1:8000 у браузері.

## Як користуватись

1. (Необов'язково) оберіть одну з десяти запропонованих Gemini-ідей
   вгорі сторінки - тема підставиться автоматично.
2. Або введіть свою тему для промту вручну.
3. Оберіть мову. Стиль відео завжди кінематографічний - інших
   варіантів свідомо немає. Тривалість відео окремо не обирається -
   Gemini сам пише текст на природних ~25-30 секунд озвучки.
4. Натисніть «Створити промт».
5. Спостерігайте за прогресом (сценарій → озвучка).
6. Перегляньте сценарій: відредагуйте текст чи промт будь-якої сцени,
   якщо потрібно (озвучка для зміненої репліки перегенерується
   автоматично), і натисніть «Затвердити сценарій».
7. Дочекайтесь фінальних файлів і завантажте матеріали: сценарій
   (JSON), субтитри (SRT) та аудіофайли озвучки.
8. Для кожної сцени скопіюйте детальний промт сцени й рекомендований
   промт руху камери у Google Flow (чи інший text-to-video інструмент)
   і отримайте готове відео сцени напряму.
9. Зведіть відео сцен, аудіофайли й субтитри разом у зручному
   відеоредакторі (CapCut, Premiere тощо).

## Структура проєкту

```
video-generator/
├── index.html / style.css / script.js   - frontend (desktop-first)
├── assets/
│   ├── images/ videos/ audio/           - місце для власних медіафайлів
│   └── music/                           - фонова музика (перший знайдений
│                                           файл використовується автоматично;
│                                           якщо порожньо - генерується тиха
│                                           тестова доріжка)
├── output/<job_id>/                     - результати кожної згенерованої задачі
└── backend/
    ├── server.py            - FastAPI застосунок, API, job-конвеєр
    ├── ai.py                 - єдина точка підключення AI API
    ├── camera_movements.py   - бібліотека промтів руху камери
    ├── transitions.py         - бібліотека промтів переходів між сценами
    ├── script_generator.py   - генерація сценарію та розбиття на сцени
    ├── voice_generator.py    - озвучка (edge-tts) + вимірювання реальної тривалості
    ├── subtitles.py          - генерація .srt субтитрів
    └── trends.py              - десять ідей тем від Gemini
```

## API

Ключі задаються в `.env` (`GEMINI_API_KEY`) і
ніколи не потрапляють у frontend JavaScript.

- `generate_script_scenes_with_ai()` - Google Gemini API для тексту сценарію,
  детального промту сцени й промту руху камери (реалізовано)
- `generate_voice_with_ai()` - edge-tts для озвучки (реалізовано,
  ключа не потребує)

Генерації картинок і відео немає - користувач отримує відео сцени сам,
поза застосунком (наприклад через Google Flow), за готовими промтами
з результату.

Щоб замінити будь-який AI-виклик на інший сервіс (наприклад Google
Cloud TTS замість edge-tts), достатньо переписати відповідну функцію в
`backend/ai.py` - решта коду не зміниться.

Кожен `*_generator.py` використовує відповідний зовнішній сервіс.
Помилки сервісів передаються в інтерфейс, а не маскуються локальними
даними.
