# AI Video Generator (DEMO)

Локальний вебзастосунок для автоматизованого створення коротких
вертикальних відео (YouTube Shorts / TikTok) з однієї теми:

`ідея → сценарій → сцени → візуал → озвучка → субтитри → монтаж → MP4`

Це **DEMO-версія**: працює повністю локально, без платних AI-сервісів.
Сценарій пише безкоштовний Gemini API (з локальним шаблоном як
резервним варіантом), той самий Gemini-виклик одразу пише і детальний
англомовний промт зображення для кожної сцени, візуал за цим промтом
генерує безкоштовний Pollinations.ai, а озвучку синтезує безкоштовний
edge-tts (усі три - з локальними заглушками як резервним варіантом,
якщо сервіс недоступний). Увесь конвеєр (включно з монтажем через
FFmpeg) при цьому працює по-справжньому і видає готовий MP4.

**Синхронізація відео/аудіо/субтитрів:** тривалість кожної сцени не
фіксована наперед - вона визначається РЕАЛЬНОЮ тривалістю згенерованої
озвучки (voice_generator вимірює аудіофайл через ffprobe вже після
синтезу мовлення). Тому субтитри, довжина відеокліпу сцени й голос
завжди збігаються, скільки б не тривала репліка.

**Числа в озвучці та субтитрах:** Gemini генерує для кожної сцени
`voice_text` (для голосу, числа словами у правильному відмінку: «у
1986 році» -> «у тисяча дев'ятсот вісімдесят шостому році») і
`subtitle` (для екрану, числа цифрами: «у 1986 році»).

**Динамічні субтитри:** текст на екрані показується без фонової
підложки (лише чорне обведення для читабельності), і слово, яке зараз
"звучить", підсвічується жовтим. Тривалість підсвічування кожного
слова пропорційна його довжині символів у межах тривалості сцени - це
працює однаково незалежно від того, чи вдалось згенерувати реальну
озвучку, чи ні.

## Технології

- Frontend: HTML/CSS/JavaScript (без фреймворків)
- Backend: Python, FastAPI
- Монтаж: FFmpeg (викликається через subprocess)

## Встановлення

1. Встановіть FFmpeg (потрібен у PATH):
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - macOS: `brew install ffmpeg`
   - Windows: завантажте з ffmpeg.org і додайте `ffmpeg.exe` у PATH

2. Встановіть залежності Python:
   ```
   pip install -r requirements.txt
   ```

3. (Необов'язково) створіть файл `.env` на основі `.env.example`:
   ```
   cp .env.example .env
   ```
   Поки ключі порожні - застосунок автоматично працює в DEMO-режимі.

   Щоб сценарій писав реальний AI (безкоштовно), отримайте ключ на
   https://aistudio.google.com/apikey і впишіть його як `GEMINI_API_KEY`
   у `.env`. Якщо запит до Gemini не вдасться (немає ключа, немає
   інтернету, ліміт вичерпано) - застосунок автоматично використає
   локальний DEMO-шаблон, нічого не зламавши.

   Візуал (Pollinations.ai) і озвучка (edge-tts) ключів не потребують -
   працюють одразу "з коробки". Обидва - публічні безкоштовні сервіси
   без офіційного SLA, тому теоретично можуть стати недоступними на
   деяких хостингах чи змінитися без попередження - якщо так станеться,
   застосунок автоматично перейде на тестове зображення/тишу, нічого не
   зламавши.

   Примітка: Gemini також уміє генерувати зображення ("Nano Banana"),
   але на безкоштовному тарифі Gemini квота для зображень дорівнює
   нулю (потрібен платний білінг) - тому для реальної безкоштовності
   обрано Pollinations.ai.

## Запуск

З кореня проєкту:
```
uvicorn backend.server:app --reload
```
Відкрийте http://127.0.0.1:8000 у браузері.

## Як користуватись

1. Введіть тему відео.
2. Оберіть тривалість (30 / 60 / 90 секунд), стиль і мову.
3. Натисніть «Створити відео».
4. Спостерігайте за прогресом по етапах (сценарій → сцени → візуал →
   озвучка → субтитри → монтаж → експорт).
5. Після завершення отримайте: готовий MP4, сценарій (JSON), субтитри
   (SRT), зображення сцен та аудіофайли озвучки.

## Структура проєкту

```
video-generator/
├── index.html / style.css / script.js   - frontend (desktop-first)
├── assets/
│   ├── images/ videos/ audio/           - місце для власних медіафайлів
│   ├── music/                           - фонова музика (перший знайдений
│   │                                       файл використовується автоматично;
│   │                                       якщо порожньо - генерується тиха
│   │                                       тестова доріжка)
│   └── fonts/                           - шрифт для субтитрів (DejaVu Sans)
├── output/<job_id>/                     - результати кожної згенерованої задачі
└── backend/
    ├── server.py            - FastAPI застосунок, API, job-конвеєр
    ├── ai.py                 - єдина точка підключення платних AI API
    ├── script_generator.py   - генерація сценарію та розбиття на сцени
    ├── scene_generator.py    - візуал сцен (Pollinations.ai за промтом від Gemini)
    ├── voice_generator.py    - озвучка (edge-tts) + вимірювання реальної тривалості
    ├── subtitles.py          - генерація .srt та накладання субтитрів
    └── editor.py              - монтаж фінального відео через FFmpeg
```

## Підключення реальних API пізніше

Ключі задаються в `.env` (`GEMINI_API_KEY`, `OPENAI_API_KEY`,
`VIDEO_API_KEY`, `TTS_API_KEY`) і ніколи не потрапляють у frontend
JavaScript.

- `generate_script_scenes_with_ai()` - Gemini API для тексту сценарію
  та промтів зображень (реалізовано)
- `generate_visual_with_ai()` - Pollinations.ai для генерації зображень
  сцен (реалізовано, ключа не потребує)
- `generate_voice_with_ai()` - edge-tts для озвучки (реалізовано,
  ключа не потребує)

Усі три AI-виклики вже підключені. Щоб замінити будь-який з них на
інший сервіс (наприклад платний Stable Diffusion/DALL-E замість
Pollinations, чи Google Cloud TTS замість edge-tts), достатньо
переписати відповідну функцію в `backend/ai.py` - решта коду не
зміниться.

Кожен `*_generator.py` модуль вже викликає свою `ai.*_with_ai()`
функцію першою і використовує локальну DEMO-логіку, лише якщо ключа
немає (`None`). Це дозволяє замінювати сервіси, не чіпаючи решту коду.

## Обмеження цієї версії (свідомо)

Без авторизації, без бази даних, без мобільної адаптації, без
платіжної системи, без автозавантаження на YouTube - усе це поза
межами першої DEMO-версії за початковим завданням.
