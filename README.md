# AI Video Generator (DEMO)

Локальний вебзастосунок для автоматизованої підготовки матеріалів для
коротких вертикальних відео (YouTube Shorts / TikTok) з однієї теми:

`ідея → сценарій → сцени → візуал → озвучка → субтитри → готові файли`

Це **DEMO-версія**: працює повністю локально, без обов'язкових платних
AI-сервісів (крім генерації картинок сцен і необов'язкової генерації
відео-сцен через fal.ai, див. нижче). Сценарій пише безкоштовний
Gemini API (з локальним шаблоном як резервним варіантом), той самий
Gemini-виклик одразу пише і детальний англомовний промт зображення для
кожної сцени, візуал за цим промтом генерує платний fal.ai (модель
FLUX.1 [schnell], копійки за картинку), а озвучку синтезує безкоштовний
edge-tts (усі - з локальними заглушками як резервним варіантом, якщо
сервіс недоступний або ключа немає).

**Без автоматичного монтажу:** застосунок видає готові МАТЕРІАЛИ
(картинки/відео сцен, аудіофайли озвучки, .srt субтитри, script.json),
а не готовий MP4 - фінальний монтаж користувач робить сам у будь-якому
відеоредакторі (CapCut, Premiere тощо). Автоматичний FFmpeg-монтаж
(колишній `backend/editor.py`) свідомо повністю прибрано з проєкту - і
з основного пайплайна, і з тестової панелі - він був найважчим CPU-
навантаженням і найчастішою причиною примусових рестартів на слабкому
безкоштовному хостингу.

**Синхронізація відео/аудіо/субтитрів:** тривалість кожної сцени не
фіксована наперед - вона визначається РЕАЛЬНОЮ тривалістю згенерованої
озвучки (voice_generator вимірює аудіофайл через ffprobe вже після
синтезу мовлення). Тому субтитри, довжина відеокліпу сцени й голос
завжди збігаються, скільки б не тривала репліка.

**Числа в озвучці та субтитрах:** Gemini генерує для кожної сцени
`voice_text` (для голосу, числа словами у правильному відмінку: «у
1986 році» -> «у тисяча дев'ятсот вісімдесят шостому році») і
`subtitle` (для екрану, числа цифрами: «у 1986 році»).

Кожен візуальний промт для генерації картинки завжди містить
кінематографічні характеристики (освітлення, композиція, якість
кінокадру) незалежно від обраного стилю - переходи між сценами й
підсвічування субтитрів слово-за-словом користувач тепер додає сам
при монтажі, у своєму відеоредакторі.

**Популярні ідеї (з YouTube):** на головній сторінці над формою -
список трендових відео в одній фіксованій ніші (цікаві факти, наука/
технології, загадкові історії - `NICHE_QUERIES` у `backend/trends.py`),
відсортований від найбільшої кількості реальних переглядів до
найменшої. Список оновлюється у фоні автоматично (раз на 3 години -
пошук за нішею коштує значно дорожчої квоти YouTube API, ніж просто
"найпопулярніше") і має кнопку "Оновити" для примусового оновлення.
Клік на ідею підставляє її назву як тему відео. Без `YOUTUBE_API_KEY`
показується невеликий локальний DEMO-список тієї самої ніші - як і
решта AI-функцій, ніколи не ламає застосунок.

## Технології

- Frontend: HTML/CSS/JavaScript (без фреймворків)
- Backend: Python, FastAPI
- Монтаж: FFmpeg (викликається через subprocess)

## Встановлення

1. Встановіть FFmpeg (потрібен у PATH):
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - macOS: `brew install ffmpeg`
   - Windows: завантажте з ffmpeg.org і додайте `ffmpeg.exe` у PATH

2. Встановіть залежності Python:
   ```
   pip install -r requirements.txt
   ```

3. (Необов'язково) створіть файл `.env` на основі `.env.example`:
   ```
   cp .env.example .env
   ```
   Поки ключі порожні - застосунок автоматично працює в DEMO-режимі.

   Щоб сценарій писав реальний AI (безкоштовно), отримайте ключ на
   https://aistudio.google.com/apikey і впишіть його як `GEMINI_API_KEY`
   у `.env`. Якщо запит до Gemini не вдасться (немає ключа, немає
   інтернету, ліміт вичерпано) - застосунок автоматично використає
   локальний DEMO-шаблон, нічого не зламавши.

   Озвучка (edge-tts) ключа не потребує - працює одразу "з коробки".
   Це публічний безкоштовний сервіс без офіційного SLA, тому теоретично
   може стати недоступним чи змінитися без попередження - якщо так
   станеться, застосунок автоматично перейде на тестову тишу, нічого
   не зламавши.

   Візуал генерує fal.ai (модель FLUX.1 [schnell], без водяного знаку) -
   платно, копійки за картинку (~$0.003-0.025). Отримайте ключ на
   https://fal.ai/dashboard/keys і впишіть як `FAL_API_KEY` у `.env`
   (той самий ключ використовується і для оживлення сцен рухом нижче).
   Без ключа (чи якщо запит не вдався) для сцени створюється тестове
   кольорове зображення-заглушка.

   Раніше картинки генерував безкоштовний Hugging Face Inference API,
   але його місячна квота регулярно вичерпувалась (HTTP 402) -
   вирішено перейти повністю на платний fal.ai. Пробували й
   Pollinations.ai як безкоштовний резерв, але він завжди додає
   водяний знак (навіть з токеном), тому й від нього відмовились.

   Примітка: Gemini також уміє генерувати зображення ("Nano Banana"),
   але на безкоштовному тарифі Gemini квота для зображень дорівнює
   нулю (потрібен платний білінг).

   Щоб на головній сторінці показувались реальні тренди YouTube (а не
   DEMO-список), увімкніть "YouTube Data API v3" в Google Cloud Console
   і впишіть ключ як `YOUTUBE_API_KEY` у `.env`:
   https://console.cloud.google.com/apis/library/youtube.googleapis.com

   Щоб оживити окремі сцени рухом (платно), отримайте ключ на
   https://fal.ai/dashboard/keys і впишіть його як `FAL_API_KEY` у
   `.env`. Оплата на fal.ai - лише за фактичне використання, без
   підписки чи мінімального платежу (на відміну від офіційного Kling
   AI Open Platform, де мінімальний корпоративний тариф починається
   від $1550/міс - для вибіркового оживлення окремих сцен це
   невиправдано дорого). Генерація відео запускається вибірково, для
   однієї обраної сцени за раз, і лише після явного підтвердження у
   діалоговому вікні - жодних випадкових витрат коштів.

## Запуск

З кореня проєкту:
```
uvicorn backend.server:app --reload
```
Відкрийте http://127.0.0.1:8000 у браузері.

## Як користуватись

1. (Необов'язково) оберіть готову ідею зі списку популярних відео
   YouTube вгорі сторінки - тема підставиться автоматично.
2. Або введіть свою тему відео вручну.
3. Оберіть тривалість (30 / 60 / 90 секунд), стиль і мову.
4. Натисніть «Створити відео».
5. Спостерігайте за прогресом по етапах (сценарій → сцени → візуал →
   озвучка → субтитри → підготовка файлів).
6. Після завершення завантажте матеріали: сценарій (JSON), субтитри
   (SRT), зображення сцен та аудіофайли озвучки - і зведіть з них
   відео самостійно у зручному редакторі.
7. (Необов'язково, платно) для будь-якої окремої сцени натисніть
   «🎬 Оживити сцену (fal.ai, платно)» - додає рух до картинки через
   image-to-video. Промт для руху можна відредагувати перед
   натисканням (наприклад дописати опис дії камери) - спрацьовує лише
   для цієї однієї сцени й лише після підтвердження витрати коштів.

## Структура проєкту

```
video-generator/
├── index.html / style.css / script.js   - frontend (desktop-first)
├── assets/
│   ├── images/ videos/ audio/           - місце для власних медіафайлів
│   ├── music/                           - фонова музика (перший знайдений
│   │                                       файл використовується автоматично;
│   │                                       якщо порожньо - генерується тиха
│   │                                       тестова доріжка)
│   └── fonts/                           - шрифт для субтитрів (DejaVu Sans)
├── output/<job_id>/                     - результати кожної згенерованої задачі
└── backend/
    ├── server.py            - FastAPI застосунок, API, job-конвеєр
    ├── ai.py                 - єдина точка підключення платних AI API
    ├── script_generator.py   - генерація сценарію та розбиття на сцени
    ├── scene_generator.py    - візуал сцен (fal.ai за промтом від Gemini)
    ├── voice_generator.py    - озвучка (edge-tts) + вимірювання реальної тривалості
    ├── subtitles.py          - генерація .srt субтитрів
    └── trends.py              - трендові ідеї теми з YouTube Data API
```

## Підключення реальних API пізніше

Ключі задаються в `.env` (`GEMINI_API_KEY`, `FAL_API_KEY`,
`YOUTUBE_API_KEY` тощо) і ніколи не потрапляють у frontend JavaScript.

- `generate_script_scenes_with_ai()` - Gemini API для тексту сценарію
  та промтів зображень (реалізовано)
- `generate_visual_with_ai()` - fal.ai (FLUX.1 [schnell]) для
  зображень сцен (реалізовано, платно)
- `generate_voice_with_ai()` - edge-tts для озвучки (реалізовано,
  ключа не потребує)
- `generate_video_clip_with_ai()` - fal.ai (модель MiniMax Hailuo) для
  оживлення окремих сцен рухом (реалізовано, платно за фактичне
  використання, викликається вибірково)

Усі AI-виклики вже підключені. Щоб замінити будь-який з них на інший
сервіс (наприклад інший провайдер зображень замість fal.ai, чи Google
Cloud TTS замість edge-tts), достатньо переписати відповідну функцію
в `backend/ai.py` - решта коду не зміниться.

Кожен `*_generator.py` модуль вже викликає свою `ai.*_with_ai()`
функцію першою і використовує локальну DEMO-логіку, лише якщо ключа
немає (`None`). Це дозволяє замінювати сервіси, не чіпаючи решту коду.

## Обмеження цієї версії (свідомо)

Без авторизації, без бази даних, без мобільної адаптації, без
платіжної системи, без автозавантаження на YouTube - усе це поза
межами першої DEMO-версії за початковим завданням.
